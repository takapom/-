Current Architecture

自然言語からSITLドローン制御までの実行ハーネス

Codexは自然言語をMission IRへ正規化し、決定的なValidatorとEmitterがSITL向けMAVLink commandへ変換する。 LLMは低レベル制御を直接行わず、ハーネスがPreflight、分割goto、進捗監視、評価ログを担当する。

Primary Flow

実行パイプライン

Mission IR first

Input

日本語タスク

例: 「Alexander Maconochie Centreまで行って」

Codex adapter

Intent Normalizer / Mission IR Generator

地名、ローカル相対座標、待機、着陸意図を型付きIRへ寄せる。

Resolution

Local Registry / GeoResolver

辞書内地点はlocal_places、辞書外地名はNominatim/Overpass候補からlat/lonへ。

Gate

Validator

高度、速度、geofence、battery、危険施設、曖昧候補を決定的に判定。

Emitter

Mission IR -> MAVLink commands

arm、takeoff、goto_local_ned、hover、landへ固定変換。

SITL execution

MavlinkSitlClient / ArduPilot SITL / QGroundControl

Preflightを通過した場合だけ、既存SITL endpointへcommandを送信。
